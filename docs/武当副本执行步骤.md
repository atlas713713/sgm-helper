# 武当 10–75 级副本执行步骤

本文是地球助手复刻武当副本逻辑的对照基准。内容来自武当 APK 的 `Dungeon10Action` 至
`Dungeon75Action`、70 级 `Dungeon70Action2`、`NPCDialog` 和 `Console` 反编译结果。
坐标均为游戏地图坐标；NPC 点击坐标为 1280×720 屏幕坐标。

## 一、所有副本共用的入场流程

1. 回城并等待主城地图加载完成。
2. 前往驻地引路员：
   - 洛阳、成都、建业：地图坐标 `(200,31)`。
   - 其他主城：地图坐标 `(210,33)`。
3. 到达后点击 NPC 快捷键 `(1208,410)`。
4. 只 OCR NPC 名字标题区域，确认标题为“驻地引路员”，点击第一行 `(251,450)`。
5. 等待进入“副本宫殿（一般）”。
6. 前往对应副本入口，宫殿坐标均为 `y=16`：

   | 等级 | 副本 | 宫殿入口 x |
   |---:|---|---:|
   | 10 | 桃园结义 | 26 |
   | 20 | 枭雄崛起 | 42 |
   | 30 | 三公战华雄 | 58 |
   | 40 | 十常侍之乱 | 73 |
   | 50 | 孙坚与玉玺 | 89 |
   | 60 | 界桥之战 | 105 |
   | 65 | 三英战吕布 | 121 |
   | 70 | 二狼劫献帝 | 136 |
   | 75 | 濮阳之战 | 152 |

7. 点击 NPC 快捷键，确认副本名后按“第四行、第三行”进入副本驻地。
8. 前往入口 NPC。通常坐标为 `(100,16)`；60 级是 `(102,16)`，70 级是 `(100,17)`。
9. 点击 NPC 快捷键，确认入口 NPC 标题，再执行该副本专属的固定行序列。
10. 等待副本地图加载，打开右侧自动寻路面板，开始按分段坐标执行。

## 二、NPC 对话的固定 OCR 和点击规则

武当的 `NPCDialog` 固定布局如下：

| 内容 | 武当区域/点击点 |
|---|---|
| NPC 名字 | 原始区域约 `(141,209)-(361,235)` |
| 第一行 | `(251,450)` |
| 第二行 | `(251,512)` |
| 第三行 | `(251,574)` |
| 第四行 | `(176,636)` |
| NPC 快捷键 | `(1208,410)` |

地球助手只 OCR 扩大后的标题区域 `(120,195)-(390,245)`。这个区域仍然只覆盖 NPC 名字，
不覆盖副本进度条、对话正文和按钮文字，因此不能把“副本进度”等文字误判成 NPC 对话框。
每次固定坐标点击前，都必须先确认当前 NPC 标题正确。

入口和出口的完整点击序列：

| 等级 | 入口 NPC | 入场行序列 | 武当配置的关键按钮 | 出口 NPC | 离场行序列 | 武当配置的奖励按钮 |
|---:|---|---|---|---|---|---|
| 10 | 邹靖 | `3 → 3` | 进入 | 义勇军刘玄德 | `4 → 4` | 收下奖赏 |
| 20 | 曹嵩 | `4 → 4 → 3` | 详情告知、下一步 | 骑都尉曹操 | `4 → 4` | 领取奖赏 |
| 30 | 乱军太平道长 | `2 → 3 → 3` | 黄天、进入 | 乱军太平道长 | `4 → 4` | 第四行离场 |
| 40 | 长乐宫官吏 | `3 → 3` | 放弃闯入、离开 | 袁绍 | `4 → 4` | 领取奖励 |
| 50 | 历战老兵 | `4 → 3 → 3` | 下一步、入场、进入 | 孙坚 | `4 → 4` | 第四行离场 |
| 60 | 说书人 | `4 → 3 → 3` | 开始神游、进入 | 公孙瓒 | `4 → 4` | 答谢公孙瓒 |
| 65 | 说书人 | `3 → 3 → 3` | 开始神游、进入 | 刘备 | `4 → 4` | 收下战利品 |
| 70 | 毛玠 | `4 → 3 → 3` | 下一步、出发、进入 | 曹操 | `4 → 4 → 4` | 下一步、收下战利品 |
| 75 | 吕布 | `4 → 3 → 3` | 下一步、出发、进入 | 陈宫 | `4 → 4 → 4` | 下一步、收下战利品 |

注意：70、75 级的武当出口逻辑是在识别到出口 NPC 后连续点击第四行三次。也就是先推进
剧情/“下一步”，再完成“离开/收下战利品”，不能只点一次或两次。

## 三、10 级：桃园结义

- 驻地：幽州边境。
- 入口 NPC：邹靖。
- 地图：599，方向从右向左。
- 入场对话：`第三行 → 第三行`。

执行顺序：

1. `x=599..504`：搜索 7 级或 10 级敌人；没有目标时每次向左移动随机 40–49 格，
   最远推进到门点 `(505,27)`。
2. `x=500..386`：继续搜索 7 级或 10 级敌人；推进到 `(387,27)`。
3. `x=382..168`：只搜索 10 级阵旗/敌人；推进到 `(170,27)`。这一段不能只移动。
4. `x=159..39`：继续只搜索 10 级阵旗/敌人；推进到 `(38,27)`。
5. `x=38..18`：切换到离场步骤，前往 `(25,27)`。
6. 点击 NPC 快捷键，确认“义勇军刘玄德”，执行 `第四行 → 第四行`，领取“收下奖赏”并离开。

## 四、20 级：枭雄崛起

- 驻地：曹公府。
- 入口 NPC：曹嵩。
- 地图：599，方向从右向左。
- 入场对话：`第四行（详情告知）→ 第四行 → 第三行（下一步）`。

执行顺序：

1. `x=599..478`：搜索 18 级或 20 级敌人，向左随机推进 40–49 格，门点 `(480,27)`。
2. `x=474..348`：不搜索敌人，直接走到 `(350,27)`。
3. `x=338..206`：先处理本段 BOSS，再处理 20 级阵旗，推进到 `(211,27)`。
4. `x=199..91`：处理 20 级阵旗并继续向左推进。
5. `x=91..31`：先处理本段 BOSS，再处理 20 级阵旗，推进到 `x=31`。
6. `x=31..18`：不再搜怪，立即切换离场，前往 `(22,27)`。
7. 点击 NPC 快捷键，确认“骑都尉曹操”，执行 `第四行 → 第四行`，领取奖赏并离开。

## 五、30 级：三公战华雄

- 驻地：乱军营寨。
- 入口/出口 NPC：乱军太平道长；部分资源仍写作“黄巾太平道长”，OCR 两者都接受。
- 地图：599，方向从右向左。
- 入场对话：`第二行（黄天）→ 第三行 → 第三行（进入）`。

执行顺序：

1. `x=599..451`：只搜索 30 级敌人；推进到 `(458,4)`。
2. `x=448..301`：只搜索 30 级敌人；推进到 `(304,27)`。
3. `x=297..151`：只搜索名字为“董军阵旗”的目标；推进到 `(174,4)`。
4. `x=148..33`：继续只搜索“董军阵旗”；推进到 `(32,27)`。
5. `x=32..20`：切换离场，前往 `(24,27)`。
6. 确认出口 NPC 标题，执行 `第四行 → 第四行` 离开。

## 六、40 级：十常侍之乱

- 驻地：长乐宫。
- 入口 NPC：长乐宫官吏。
- 地图：599，方向从右向左；副本起点约 `(570,25)`。
- 入场对话：`第三行 → 第三行`。

执行顺序：

1. `x=599..32`：使用武当的 BOSS 搜索逻辑；没有目标时每次向左随机移动 40–49 格，
   最终到 `x=32`。
2. `x=31..13`：切换出口，前往 `(25,25)`。
3. 点击 NPC 快捷键，确认“袁绍”，执行 `第四行 → 第四行`，领取奖励并离开。

## 七、50 级：孙坚与玉玺

- 驻地：追忆之地。
- 入口 NPC：历战老兵。
- 地图：599，方向从左向右。
- 入场对话：`第四行（下一步）→ 第三行（入场/进入）→ 第三行`。

执行顺序：

1. 开场必须依次走三个点：`(46,6) → (46,45) → (60,45)`，不能从出生点直接点 `(60,45)`。
2. `x=50..110`：搜索本段 BOSS，向右随机推进 40–49 格，下一分段从 `x=112` 开始。
3. `x=112..194`：搜索 BOSS，向 `x=205` 推进。
4. `x=205..287`：搜索 BOSS，向 `x=291` 推进。
5. `x=291..308`：与孙坚交互，确认 NPC 标题后点击第四行“交给我吧”。
6. `x=312..388`：搜索 BOSS，向 `x=399` 推进。
7. `x=399..484`：搜索 BOSS，向 `x=495` 推进。
8. `x=495..581`：搜索 BOSS，向 `x=583` 推进。
9. `x=583..599`：切换离场，回到出口点 `(570,25)`。
10. 确认“孙坚”，执行 `第四行 → 第四行` 离开。

## 八、60 级：界桥之战

- 驻地：盘河桥西。
- 入口 NPC：说书人。
- 地图：599，多房间传送。
- 入场对话：`第四行（开始神游）→ 第三行（进入）→ 第三行`。

这里不能按 x 单调推进；武当按传送房间状态执行：

1. `x<=98`：处理第一战斗房 BOSS；清空后依次走 `(71,10) → (71,4)` 进入房间。
2. 传送到 `x=505..528` 后，点击 NPC 快捷键一次，离开第一战斗房。
3. `x=105..198`：处理第二战斗房 BOSS；清空后依次走 `(70,40) → (70,46)`。
4. 传送到 `x=531..553` 后，点击 NPC 快捷键一次，离开第二战斗房。
5. `x=205..298`：处理第三战斗房 BOSS；清空后依次走 `(90,27) → (94,27)`。
6. `x=305..398`：继续处理 BOSS；清空后依次走 `(380,27) → (394,27)`。
7. 传送到中央区域 `x=556..581` 后，先走到 `(570,27)`，再点击 NPC 快捷键两次。
8. `x=405..479`：处理最终 BOSS；清空后走到 `(486,25)`。
9. `x=480..498`：前往出口 `(486,27)`。
10. 确认“公孙瓒”，执行 `第四行 → 第四行`，点击“答谢公孙瓒”并离开。

## 九、65 级：三英战吕布

- 驻地：虎牢关近郊。
- 入口 NPC：说书人。
- 地图：599，方向从左向右。
- 一般副本优先敌人等级：64；精英副本为 68。
- 入场对话：`第三行 → 第三行 → 第三行`。

执行顺序：

1. `x<=58`：走到 `(34,22)`，与刘备交互，确认标题后点击第三行“出击”。
2. `x=79..230`：搜索本段 BOSS，优先 64 级目标，推进到 `(245,27)`。
3. `x=231..250`：通过门点，进入 `x>=252` 的下一段。
4. `x=252..437`：搜索吕布/BOSS；清空后必须依次走
   `(409,30) → (410,10) → (410,4)`，不能直接点击最后一个点。
5. `x=440..537`：搜索 BOSS，推进到 `x=538`。
6. `x=538..580`：切换离场，前往 `(560,27)`。
7. 确认“刘备”，执行 `第四行 → 第四行`，收下战利品并离开。

## 十、70 级：二狼劫献帝

- 驻地：安邑郊外。
- 入口 NPC：毛玠。
- 地图：599，护送方向从左向右。
- 入场对话：`第四行（下一步）→ 第三行（出发/进入）→ 第三行`。

执行顺序：

1. `x<120`：保护“马车”，优先攻击“长安城驻军队长”和“长安白虎大门”，推进到 `(115,27)`。
2. `x=120..568`：继续护送；绝不把“马车”选为攻击目标。武当要求马车血量不低于 90%。
3. 当前段没有可攻击目标后，推进到出口 `(560,27)`。
4. 确认“曹操”，严格执行 `第四行 → 第四行 → 第四行`：
   先推进“下一步”，再完成“离开/收下战利品”。

70 级旧类有反编译缺损，本节以同一 APK 中可完整读取的 `Dungeon70Action2` 为准。

## 十一、75 级：濮阳之战

- 驻地：濮阳城外。
- 入口 NPC：吕布。
- 地图：199，方向从左向右。
- 入场对话：`第四行（下一步）→ 第三行（出发/进入）→ 第三行`。
- BOSS 优先顺序：`吕虔 → 于禁 → 李典 → 夏侯渊`。

执行顺序：

1. `x<65`：按上述名字顺序搜索并攻击，推进到 `(73,27)`。
2. `x=65..78`：通过第一门点 `(73,27)`。
3. `x=79..129`：继续按名字优先级搜索，推进到阵旗点 `(130,27)`。
4. `x=130..179`：继续搜索剩余 BOSS，推进到出口 `(187,27)`。
5. `x>=180`：切换离场。
6. 确认“陈宫”，严格执行 `第四行 → 第四行 → 第四行`：
   先推进“下一步”，再完成“离开/收下战利品”。

## 十二、战斗 OCR 和恢复边界

1. 10、20、30、65、70、75 级使用上方引路列表；40、50、60 级使用下方列表。
2. 上方只读取固定中心线 `y=151/206/261/316/371`；下方只读取
   `y=294/349/404`。
3. 敌人 OCR 横向只接受 `x=950..1235`。副本进度条不在这些固定敌人行内，必须忽略。
4. 左右推进距离复刻武当的随机 `40..49` 格，不固定为 45。
5. 每次攻击后重新识别当前位置和固定敌人行；没有敌人才执行本分段的门点/传送点。
6. 同一门点连续停留时，才执行对应副本的脱困坐标；不得跳过尚未完成的战斗分段。
