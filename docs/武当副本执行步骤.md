# 武当 10–165 级副本执行步骤

本文是地球助手复刻武当副本逻辑的对照基准。内容来自武当 APK 的 `Dungeon10Action` 至
`Dungeon165Action`、70 级 `Dungeon70Action2`、`DungeonUtil`、`NPCDialog` 和
`Console` 反编译结果。坐标均为游戏地图坐标；NPC 点击坐标为 1280×720 屏幕坐标。

当前实现也按武当结构拆分：共享流程位于 `BaseDungeonAction`，
10、20、30、40、50、60、65、70、75、80、90、105、120、135、150、165 级分别由独立的
`DungeonXXAction` 类保存地图、NPC、对话行和副本路线。

## 一、所有副本共用的入场流程

1. 回城并等待主城地图加载完成。
2. 前往驻地引路员：
   - 洛阳、成都、建业：地图坐标 `(200,31)`。
   - 其他主城：地图坐标 `(210,33)`。
3. 到达后点击 NPC 快捷键 `(1208,410)`。
4. 只 OCR NPC 名字标题区域，确认标题为“驻地引路员”，点击第一行 `(251,450)`。
5. 等待进入“副本宫殿（一般）”。
6. 前往对应副本入口，宫殿坐标均为 `y=16`：

   | 等级 | 副本 | 宫殿入口 x |
   |---:|---|---:|
   | 10 | 桃园结义 | 26 |
   | 20 | 枭雄崛起 | 42 |
   | 30 | 三公战华雄 | 58 |
   | 40 | 十常侍之乱 | 73 |
   | 50 | 孙坚与玉玺 | 89 |
   | 60 | 界桥之战 | 105 |
   | 65 | 三英战吕布 | 121 |
   | 70 | 二狼劫献帝 | 136 |
   | 75 | 濮阳之战 | 152 |
   | 80 | — | 169 |
   | 90 | — | 184 |
   | 105 | — | 216 |
   | 120 | — | 232 |
   | 135 | — | 248 |
   | 150 | — | 263 |
   | 165 | — | 279 |

   所有副本名、驻地名和入口/出口 NPC 名都在 APK 的
   `res/values/arrays.xml`（`dungeon_list_cn` / `dungeon_pro_list_cn`）里，不是服务端下发的，
   所以每一级都做副本名 OCR 校验。80 级以上的名字见第十三节。

7. 点击 NPC 快捷键，确认副本名后按“第四行、第三行”进入副本驻地
8. 前往入口 NPC。通常坐标为 `(100,16)`；60 级是 `(102,16)`，70 级是 `(100,17)`。
9. 点击 NPC 快捷键，确认入口 NPC 标题，再执行该副本专属的固定行序列。
10. 等待副本地图加载，打开右侧自动寻路面板，开始按分段坐标执行。

## 一点五、每个副本的执行次数（武当 `id → count` 逻辑）

武当不是勾选后每个副本只执行一次，也不是所有副本共用一个总次数。副本选择项实际保存为
`IdValueEntity(id, value)`：`id` 是副本等级，`value` 是该等级要完成的场次；一般、精英和
扫荡分别使用 `pick_dungeon_id_count`、`pick_dungeon_pro_id_count`、
`pick_dungeon_sd_id_count`。`QuickDungeonAction` 会先完成当前 `id` 的 `value` 场，
再移动到列表中的下一个 `id`。

地球助手现在在每个等级右侧提供独立次数选择，默认 3 次（可选 1–20 次）。实战副本和扫荡
都按“当前等级完成目标次数 → 下一个等级”执行；进入 NPC 后发现副本次数用完时，当前等级会
跳过，不把这次失败计入完成场次。背包处理的间隔计数仍按实际完成的副本场次计算，与每个等级
的执行次数设置互相独立。

## 二、NPC 对话的固定 OCR 和点击规则

武当的 `NPCDialog` 固定布局如下：

| 内容 | 武当区域/点击点 |
|---|---|
| NPC 名字 | 原始区域约 `(141,209)-(361,235)` |
| 第一行 | `(251,450)` |
| 第二行 | `(251,512)` |
| 第三行 | `(251,574)` |
| 第四行 | `(176,636)` |
| NPC 快捷键 | `(1208,410)` |

地球助手只 OCR 扩大后的标题区域 `(120,195)-(390,245)`。这个区域仍然只覆盖 NPC 名字，
不覆盖副本进度条、对话正文和按钮文字，因此不能把“副本进度”等文字误判成 NPC 对话框。
每次固定坐标点击前，都必须先确认当前 NPC 标题正确。

入口和出口的完整点击序列：

| 等级 | 入口 NPC | 入场行序列 | 武当配置的关键按钮 | 出口 NPC | 离场行序列 | 武当配置的奖励按钮 |
|---:|---|---|---|---|---|---|
| 10 | 邹靖 | `3 → 3` | 进入 | 义勇军刘玄德 | `4 → 4` | 收下奖赏 |
| 20 | 曹嵩 | `4 → 4 → 3` | 详情告知、下一步 | 骑都尉曹操 | `4 → 4` | 领取奖赏 |
| 30 | 乱军太平道长 | `2 → 3 → 3` | 黄天、进入 | 乱军太平道长 | `4 → 4` | 第四行离场 |
| 40 | 长乐宫官吏 | `3 → 3` | 放弃闯入、离开 | 袁绍 | `4 → 4` | 领取奖励 |
| 50 | 历战老兵 | `4 → 3 → 3` | 下一步、入场、进入 | 孙坚 | `4 → 4` | 第四行离场 |
| 60 | 说书人 | `4 → 3 → 3` | 开始神游、进入 | 公孙瓒 | `4 → 4` | 答谢公孙瓒 |
| 65 | 说书人 | `3 → 3 → 3` | 开始神游、进入 | 刘备 | `4 → 4` | 收下战利品 |
| 70 | 毛玠 | `4 → 3 → 3` | 下一步、出发、进入 | 曹操 | `4 → 4 → 4` | 下一步、收下战利品 |
| 75 | 吕布 | `4 → 3 → 3` | 下一步、出发、进入 | 陈宫 | `4 → 4 → 4` | 下一步、收下战利品 |

注意：70、75 级的武当出口逻辑是在识别到出口 NPC 后连续点击第四行三次。也就是先推进
剧情/“下一步”，再完成“离开/收下战利品”，不能只点一次或两次。

## 三、10 级：桃园结义

- 驻地：幽州边境。
- 入口 NPC：邹靖。
- 地图：599，方向从右向左。
- 入场对话：`第三行 → 第三行`。

执行顺序：

1. `part0` `x=599..504`：搜索 7 级或 10 级敌人；没有目标时每次向左移动随机 40–49 格，
   下限是 `min(599,504)-5=499`。`x<514` 时改为直接走门点 `(505,27)`。
   卡在 `x=514` 时的脱困点是 `(550,25)`。
2. `part1` `x=500..386`：同样搜索 7 级或 10 级敌人，随机推进下限 `381`；
   `x<397` 时走门点 `(387,27)`。卡在 `x=397` 时脱困点是 `(450,25)`。
3. `part2` `x=382..168`：**武当这一段完全不搜怪**，只做移动：
   `x>310` 走 `(290,27)`，否则走门点 `(170,27)`。
4. `part3` `x=159..39`：先用 `FindDungeonBossAction` 找副本 BOSS，再搜 10 级阵旗，
   随机推进下限 `13`；卡在 `x=39` 时脱困点是 `(110,25)`。
5. `part4` `x=38..18`：切换到离场步骤，前往 `(25,27)`。
6. 点击 NPC 快捷键，确认“义勇军刘玄德”，执行 `第四行 → 第四行`，领取“收下奖赏”并离开。

## 四、20 级：枭雄崛起

- 驻地：曹公府。
- 入口 NPC：曹嵩。
- 地图：599，方向从右向左。
- 入场对话：`第四行（详情告知）→ 第四行 → 第三行（下一步）`。

执行顺序：

1. `part0` `x=599..478`：搜索 18 级或 20 级敌人，随机推进下限 `473`；
   `x<491` 时走门点 `(480,27)`。卡在 `x=491` 时脱困点是 `(550,25)`。
2. `part1` `x=474..348`：不搜索敌人，直接走到 `(350,27)`。
3. `part2` `x=338..206`：先处理本段 BOSS，再处理 20 级阵旗，随机推进下限 `201`；
   `x<221` 时走门点 `(211,27)`。卡在 `x=221` 时脱困点是 `(280,25)`。
4. `part3` `x=199..91`：**只处理 20 级阵旗，不找 BOSS**，随机推进下限 `26`；
   卡在 `x=91` 时脱困点是 `(170,25)`。
5. `part4` `x=91..31`：先处理本段 BOSS，再处理 20 级阵旗，随机推进下限 `13`；
   卡在 `x=31` 时脱困点是 `(70,25)`。
6. `part5` `x=31..18`：不再搜怪，立即切换离场，前往 `(22,27)`。
7. 点击 NPC 快捷键，确认“骑都尉曹操”，执行 `第四行 → 第四行`，领取奖赏并离开。

## 五、30 级：三公战华雄

- 驻地：黄巾营寨（已由当前游戏画面和地球瘦子 OCR 日志确认）。
- 入口/出口 NPC：乱军太平道长；部分资源仍写作“黄巾太平道长”，OCR 两者都接受。
- 地图：599，方向从右向左。
- 入场对话：`第二行（黄天）→ 第三行 → 第三行（进入）`。

执行顺序：

30 级和其他副本不一样：**武当在这里几乎不用随机 40–49 格推进，整条路线都是固定路点**。

实现说明：旧版反编译代码的 `part0/part1` 还保留了先尝试普通 30 级敌人的分支
（`FindEnemyAction(enemyLevels=[30])`），但当前实机要求是“进入后先到固定路点找王”。
因此本项目在 part0/part1 跳过普通敌人，保留武当 `FindDungeonBossAction` 的红名目标
检测；找不到王才继续走下一个路点。**part3 不在此列**，见下。

1. `part0` `x=599..451`：只找副本 BOSS。路点按当前 x 分段：
   - `x=580..599` → `(570,25)`
   - `x=510..579` → 第一次进入该区间先补一个 `(570,25)`（武当的 `flag570`），
     之后每次都走 `(500,25)`
   - `x=451..509` → 门点 `(458,4)`

   这两个路点的 y 是 **25**，不是 27（只有门点 `(458,4)` 例外）。
   卡在 `x=473` 时脱困点是 `(570,25)`。
2. `part1` `x=448..301`：只找副本 BOSS。
   - `x=420..448` → `(410,25)`
   - `x=350..419` → 第一次进入先补一个 `(410,25)`（`flag420`），之后走 `(340,25)`
   - `x=301..349` → 门点 `(304,27)`

   卡在 `x=317` 时脱困点是 `(430,25)`。
3. `part2` `x=297..151`：**只找副本 BOSS**，不再把“董军阵旗”当成普通 OCR 目标。
   - `x=245..297` → `(235,25)`
   - `x=205..244` → `(195,25)`
   - `x=151..204` → 门点 `(174,4)`
4. `part3` `x=148..33`：**这一段和其他分段不同**——武当先用
   `FindEnemyAction(names=["董军阵旗"])` 打阵旗，打完才走 `FindDungeonBossAction`
   找红名 BOSS。阵旗只在 part3 打，part2 完全不打。
   - `x=95..149` → `(85,25)`
   - `x=55..94` → `(45,25)`
   - `x=33..54` → 直接走出口点 `(24,27)`
   - `x>=150`（分段之间的空档）→ `toLeft`，随机 40–49 格、`y=27`，下限 `min(148,20)-5=15`
5. `part4` `x=32..20`：切换离场，前往 `(24,27)`。
6. 确认出口 NPC 标题，执行 `第四行 → 第四行` 离开。

## 六、40 级：十常侍之乱

- 驻地：长乐宫。
- 入口 NPC：长乐宫官吏。
- 地图：599，方向从右向左；副本起点约 `(570,25)`。
- 入场对话：`第三行 → 第三行`。

执行顺序：

1. `part0` `x=32..599`：只用 `FindDungeonBossAction` 找红名副本 BOSS，没有目标时
   **走固定阶梯路点**，不随机推进：

   | 当前 x | 目标 |
   |---|---|
   | `530..599` | `(520,25)` |
   | `430..529` | `(420,25)` |
   | `360..429` | `(350,25)` |
   | `285..359` | `(275,25)` |
   | `190..284` | `(180,25)` |
   | `120..189` | `(110,25)` |
   | `60..119` | `(50,25)` |
   | `< 60` | `(25,25)` |

   另外 `y<20` 或 `y>30` 时先把 y 拉回 `(x,25)`；连续卡住时走 `(x+100,25)` 两次，
   中间等 5 秒。这两条都已实现（脱困点按地图宽度夹到 599）。
2. `part1` `x=13..31`：走出口点 `(25,25)`。
3. 点击 NPC 快捷键，确认“袁绍”，执行 `第四行 → 第四行`，领取奖励并离开。

## 七、50 级：孙坚与玉玺

- 驻地：追忆之地。
- 入口 NPC：历战老兵。
- 地图：599，方向从左向右。
- 入场对话：`第四行（下一步）→ 第三行（入场/进入）→ 第三行`。

执行顺序：

1. `part0` `x<=49`：**按当前 `(x,y)` 三选一走一个点，不是一次走完三个**：
   `x<42` → `(46,6)`；`x>=42 且 y<40` → `(46,45)`；否则 → `(60,45)`。
   这样在 `(46,45)` 复活时会接着走 `(60,45)`，不会被送回 `(46,6)`。
2. `part1..part6`（`50..110`、`112..194`、`205..287`、`312..388`、`399..484`、
   `495..581`）都跑同一个 `attackPart`：先 `FindDungeonBossAction` 找红名 BOSS，
   没有目标就调用 `toRight`。
3. **`toRight` 是固定 `+30` 一步、`y=27`**，上限 `max(25,570)=570`，越界后落在 `575`；
   不是随机 40–49，也不是走到各分段的门点。分段边界只用来算卡住时的脱困点：
   **`next.x > 分段终点` 时走 `分段终点-10`，否则走 `next.x+20`**，落点同样在 `y=27`。
4. `partCenter` `x=291..308`：先点 NPC 快捷键，再在 NPCDialog 里找“交给我吧”并点击。
   武当在这里**不校验 NPC 标题**，副本中央的标题 OCR 本来就不稳。
5. `part7` `x=583..599`：切换离场。武当的 `exitPart` 是**原地连点 NPC 快捷键三次**
   （间隔 200ms），50 级根本没有 `exitLocation` 字段——第十二节表里的 `(570,25)` 是
   `toRight` 的终点，不是武当的离场坐标。本项目仍先走 `(570,25)` 再点快捷键，
   因为离场流程是统一的“关面板 → 点快捷键 → 出口对话”。
6. 确认“孙坚”，执行 `第四行 → 第四行` 离开。

## 八、60 级：界桥之战

- 驻地：盘河桥西。
- 入口 NPC：说书人。
- 地图：599，多房间传送。
- 入场对话：`第四行（开始神游）→ 第三行（进入）→ 第三行`。

这里不能按 x 单调推进。**走廊坐标 `x<=98` 会重复出现，武当靠 `partStep` 记住
下一间房**，只看 x 会一直被送回第一间：

**三间战斗房各自只打一个指定 BOSS**，用的是 `FindTargetBossAction(名字)`，房里其他
敌人一律不打：第一间 `田丰`、第二间 `文丑`、第三间 `颜良`。最终 BOSS 段才是
`FindDungeonBossAction`（红名）。**走廊里武当完全不搜怪**，只走门点。

每间房清不掉时武当会用 `toRight` 在房里逐格往前扫，**步长是随机 20–29 格**、`y=27`；
一步跨过分段终点就算这一段扫完，才去走传送点。“当前屏幕没敌人就立刻传送”会漏掉
还没进引路列表视野的 BOSS。

1. `partStep=0` 且 `x<=98`：依次走 `(71,10) → (71,4)` 进第一战斗房。
2. `x=105..198`（第一战斗房）：打田丰并扫房；扫完依次走 `(114,40) → (114,46)` 传送出去。
3. 传送到 `x=505..528` 后点一次快捷键，`partStep` 变为 1。
4. `partStep=1` 且 `x<=98`：依次走 `(70,40) → (70,46)` 进第二战斗房。
5. `x=205..298`（第二战斗房）：打文丑并扫房；扫完依次走 `(214,10) → (214,4)` 传送出去。
6. 传送到 `x=531..553` 后点一次快捷键，`partStep` 变为 2。
7. `partStep=2` 且 `x<=98`：依次走 `(90,27) → (94,27)` 进第三战斗房。
8. `x=305..398`（第三战斗房）：打颜良并扫房；扫完依次走 `(380,27) → (394,27)`。
9. 传送到中央区域 `x=556..581` 后，先走到 `(570,27)`（等队友），再点击快捷键两次。
10. `x=405..479`：找红名最终 BOSS 并扫段；扫完走到 `(486,25)`。
11. `x=480..498`：前往出口 `(486,27)`。
12. 确认“公孙瓒”，执行 `第四行 → 第四行`，点击“答谢公孙瓒”并离开。

武当每间房还有 `waitTeammate`（等队友），本项目没有实现。

## 九、65 级：三英战吕布

- 驻地：虎牢关近郊。
- 入口 NPC：说书人。
- 地图：599，方向从左向右。
- 一般副本优先敌人等级：64；精英副本为 68。
- 入场对话：`第三行 → 第三行 → 第三行`。

每个战斗分段的搜索是三层，全部严格匹配、全落空才继续推进：
`FindDungeonBossLevelAction(priorityEnemyLevels)` → `FindEnemyAction(enemyLevels, enemyNames)`。
`DungeonAction` 传进来的次选目标按副本类型不同：

| | priorityEnemyLevels | enemyLevels | enemyNames |
|---|---|---|---|
| 一般 65 | `[64]` | `[1, 63]` | — |
| 精英 65 | `[68]` | `[1]` | `["虎牢关副将"]` |

段内推进用 `toRight`，固定 30 格、`y=27`，但 **`310 <= x < 381` 这段走廊的 y 是 37**。

执行顺序：

1. `x<=58`：走到 `(34,22)`，与刘备交互，确认标题后点击第三行“出击”。
2. `x=79..230`：按上面三层搜索，推进到 `(245,27)`。
3. `x=231..250`：**武当这一段照样搜怪**，再用 `toRight` 顶进 `x>=252` 的下一段，
   不是纯移动。
4. `x=252..437`：继续搜索。`252..349` 用 `toRight` 逐格扫（`310..349` 走 `y=37`）；
   扫到 `x>=350` 才依次走 `(409,30) → (410,10) → (410,4)`，不能直接点最后一个点。
5. `x=440..537`：**这一段用的是 `FindDungeonBossAction`（红名副本 BOSS），不按等级**；
   同样先在段内扫一遍，扫到段尾才推进到 `x=538`。
6. `x=538..580`：切换离场，前往 `(560,27)`。
7. 确认“刘备”，执行 `第四行 → 第四行`，收下战利品并离开。

## 十、70 级：二狼劫献帝

- 驻地：安邑郊外。
- 入口 NPC：毛玠。
- 地图：599，护送方向从左向右。
- 入场对话：`第四行（下一步）→ 第三行（出发/进入）→ 第三行`。

**护送是一段一段推的，不能一次寻路冲到终点**。马车按自己的速度走，人跑到 560 就不再
清路了，武当因此在 part0 和 part1 都设了中途站，每一站都是一次独立寻路：

| 当前 x | 目标 |
|---|---|
| `0..29` | `(40,25)` |
| `30..79` | `(90,25)` |
| `80..119` | `(115,27)` |
| `120..219` | `(230,25)` |
| `220..319` | `(330,25)` |
| `320..439` | `(450,25)` |
| `440..529` | `(540,25)` |
| `530..550` | `(560,27)` |
| `550..568` | 切换离场 |

敌人：武当用的是 `FindEnemyAction2(levels=null, names=["长安城驻军队长","长安白虎大门"])`

2. `x>550`：切换离场，前往出口 `(560,27)`。
3. 确认“曹操”，严格执行 `第四行 → 第四行 → 第四行`：

70 级旧类有反编译缺损，本节以同一 APK 中可完整读取的 `Dungeon70Action2` 为准。
武当的 `protectMinHp=0.9`（马车血量不低于 90%）需要读血条百分比，尚未实现。

## 十一、75 级：濮阳之战

- 驻地：濮阳城外。
- 入口 NPC：吕布。
- 地图：199，方向从左向右。
- 入场对话：`第四行（下一步）→ 第三行（出发/进入）→ 第三行`。
- BOSS 优先顺序：`吕虔 → 于禁 → 李典 → 夏侯渊`（`res/values/arrays.xml` 里数组的

只有两个分段：`part0 = x<=78`、`part1 = x=79..199`。两段的搜索目标不同：

| 精英 75（id 2075） | `[1, 75, 79, 80]` |

2. `x=61..66`：走第一门点 `(73,27)`。
3. `x=67..78`：只有 `y<20` 或 `y>35` 才走 `(73,27)`，否则继续 `toRight` 往前顶。
4. `x=79..119`：按名字优先级搜索，推进到 `(130,25)`。
5. `x=120..159`：继续搜索，推进到中途站 `(170,25)`。
6. `x>=160`：切换离场，出口 `(187,27)`。
7. 确认“陈宫”，严格执行 `第四行 → 第四行 → 第四行`：
   先推进“下一步”，再完成“离开/收下战利品”。

注意 `(130,25)` 和 `(170,25)` 的 y 是 **25**，只有 `exitLocation (187,27)` 是 27。

## 十二、战斗 OCR 和恢复边界

1. 10、20、30、65、70、75 级使用上方引路列表；40、50、60 级使用下方列表。
2. 上方只读取固定中心线 `y=151/206/261/316/371`；下方只读取
   `y=294/349/404`。
3. 敌人 OCR 横向只接受 `x=950..1235`。副本进度条不在这些固定敌人行内，必须忽略。
3.5. **NPC 快捷键 `(1208,410)` 落在引路面板敌人列表的矩形里**（`x=950..1245`，
   下边界 440）。40/50/60 用的下方行第三行在 `y=404`，和快捷键只差 6 像素——面板没
   收起就去点快捷键，等于选中第三只怪，游戏的“辅助开关”随即开打，看起来像助手在副本
   中途乱打怪。所以任何 NPC 交互前都必须先真的关掉面板，且不能靠 g04“自动寻路”模板
   判断面板状态：那个锚点在 `(1114,479)`，在列表下边界之外、不被面板遮挡。
4. 推进方式按副本区分，不是所有副本都随机走：

   | 等级 | 段内推进 | 步长 | y |
   |---|---|---|---|
   | 10、20 | `toLeft` | 随机 40–49 | 27 |
   | 30 | 固定阶梯路点；part3 的空档用 `toLeft` | 随机 40–49 | 25（part0/part1 路点）/ 27 |
   | 40 | 固定阶梯路点，完全不随机 | — | 25 |
   | 50 | `toRight` | 固定 30，上限 570（越界落 575） | 27 |
   | 60 | 房间内 `toRight`；房间之间按 `partStep` 传送 | 随机 20–29 | 27 |
   | 65 | `toRight` | 固定 30 | 27，`310..380` 走廊是 37 |
   | 70 | 固定中途站，一站一次寻路 | — | 25（终点 115/560 是 27） |
   | 75 | part0 `toRight`；part1 固定中途站 | 固定 30 | 27 / 中途站 25 |

   `toLeft`/`toRight` 的共同收尾：一步跨过分段终点就落到 `分段终点-10`，
   并且视为这一段已经扫完，下一拍才去走门点/传送点。
5. 每次攻击后重新识别当前位置和固定敌人行；没有敌人才执行本分段的门点/传送点。
6. 同一门点连续停留时，才执行对应副本的脱困坐标；不得跳过尚未完成的战斗分段。
   40 级的脱困是 `(x+100,25)` 连走两次；50 级是
   `next.x > 分段终点 ? 分段终点-10 : next.x+20`，落点在 `y=27`。
7. 敌人搜索层次按副本区分，武当每一层都是严格匹配，全落空才继续推进：

   | 等级 | 搜索顺序 |
   |---|---|
   | 30 part0/part1 | `FindEnemyAction([30])` → `FindDungeonBossAction`（本项目跳过前者） |
   | 30 part2 | `FindDungeonBossAction` |
   | 30 part3 | `FindEnemyAction(["董军阵旗"])` → `FindDungeonBossAction` |
   | 40、50 | `FindDungeonBossAction`（红名） |
   | 60 三间房 | `FindTargetBossAction("田丰"/"文丑"/"颜良")`，走廊不搜怪 |
   | 60 最终段 | `FindDungeonBossAction` |
   | 65 | `FindDungeonBossLevelAction([64/68])` → `FindEnemyAction(等级+名字)`；`440..537` 段是 `FindDungeonBossAction` |
   | 70 | `FindEnemyAction2(names)`，无等级兜底、不打任意敌人 |
   | 75 part0 | `FindEnemyAction(enemyLevels)` |
   | 75 part1 | `FindDungeonBossAction(names)` → `FindEnemyAction(enemyLevels)` |

8. 离场坐标用武当的 `exitLocation`，是每个副本的固定值，不能靠"把 x 当成 0 再问一次
   路线"推出来——从左往右打的 60/65/70/75 那样推会得到开场路点：

   | 等级 | 10 | 20 | 30 | 40 | 50 | 60 | 65 | 70 | 75 |
   |---|---|---|---|---|---|---|---|---|---|
   | exitLocation | `(25,27)` | `(22,27)` | `(24,27)` | `(25,25)` | 无 | `(486,27)` | `(560,27)` | `(560,27)` | `(187,27)` |

   50 级没有 `exitLocation`：武当的 `exitPart` 原地连点三次 NPC 快捷键。本项目仍走
   `(570,25)`（`toRight` 的终点）再点快捷键，见第七节。

## 十二点五、60/65/70/75 级精英副本

精英副本是武当 `DungeonEntity.type == 2`（一般副本是 1，试炼是 3）。
**副本里的路线、分段、门点、脱困点、出口坐标和一般副本完全一样**，
武当的 `Dungeon60Action`／`Dungeon70Action2`／`Dungeon75Action` 根本不读副本类型；
差别全部在入场，以及 65 级的优先敌人等级。

### 1. 入场差在哪

| 步骤 | 一般副本 | 精英副本 |
|---|---|---|
| 驻地引路员对话 | 点**第一行** | 点**第二行**（`GotoDungeonPalaceAction`：type 1→item1，2→item2，3→item3） |
| 宫殿地图名 | `副本宫殿(一般)` | `副本宫殿(精英)` |
| 宫殿入口 y | 16 | **20** |
| 副本名 OCR | 见下表 | 见下表（多一个“精英”前缀） |

### 2. 精英副本配置（`res/values/arrays.xml` 的 `dungeon_pro_list_cn`）

| 等级 | id | 副本名 | 驻地 | 宫殿入口 | 入口 NPC | 出口 NPC |
|---:|---:|---|---|---|---|---|
| 60 | 2060 | 精英界桥之战 | 精英盘河桥西 | `(26,20)` | 说书人 | 公孙瓒 |
| 65 | 2065 | 精英三英战吕布 | 精英虎牢关近郊 | `(41,20)` | 说书人 | 刘备 |
| 70 | 2070 | 精英二狼劫献帝 | 精英安邑郊外 | `(57,20)` | 毛玠 | 曹操 |
| 75 | 2075 | 精英濮阳之战 | **精英濮阳城内** | `(73,20)` | 吕布 | 陈宫 |

### 3. 65 级的敌人等级

武当 `Dungeon65Action` 里唯一读类型的地方：

```
priorityEnemyLevels = type == 2 ? [68] : [64]
```

`DungeonAction` 传进来的次选目标也不同：一般是 `enemyLevels=[1,63]`，
精英是 `enemyLevels=[1]` 加 `enemyNames=["虎牢关副将"]`。武当每个战斗分段先按
`priorityEnemyLevels` 找（`FindDungeonBossLevelAction`），找不到再按
`enemyLevels`＋`enemyNames` 找（`FindEnemyAction`）。两层都已按原样复刻。

### 3.5 其他读副本类型的地方

除了 65 的敌人配置，`DungeonAction` 还给 75 传了两张不同的 `enemyLevels`：
一般 `[1,74,75]`、精英 `[1,75,79,80]`。60、70 两级的敌人配置不分类型。
副本清理用的“行脚商队”坐标（`DungeonUtil.v`）也分类型，见第十五节。

### 4. 当前实现

`BaseDungeonAction.forElite(level)` 返回 `Dungeon60/65/70/75EliteAction`，
它们继承对应的一般副本类，只覆盖 `dungeonType`、`dungeonName`、`campName`、
`campNpcX`、`campNpcY`，65 级另加 `priorityEnemyLevel`／`enemyLevels`／`enemyNames`，
75 级另加 `enemyLevels`。副本名用 `精英界桥之战|界桥之战` 这种写法，两种 OCR 结果都接受。

精英 75 逐项对照（`Dungeon75Action` 一次都没读过副本类型，所以副本内完全复用）：

| 项 | 一般 75 | 精英 75 |

| id / type | 1075 / 1 | 2075 / 2 |

| 驻地里入口 NPC | `(100,16)` | `(100,16)` |
| 入口/出口 NPC | 吕布 / 陈宫 | 吕布 / 陈宫 |

## 十五、完成副本后的物品处理

武当设置页的原文是“完成普通 N 次，或精英试炼 N 次后，进行物品处理”，并分别保存
`dungeon_gear_handle_count` 与 `dungeon_pro_gear_handle_count`。因此次数是“成功领取奖励的
副本数”，不是进入副本数；没有副本次数而跳过的项目不计数。最后一个选中的副本会做一次
收尾，避免间隔大于本批副本数量时留下刚获得的装备。

本项目的对应实现位于 `DungeonBattleAutomation.finishCurrent(true)`：

1. 退出副本并领取奖励后才递增普通/精英自己的计数器。
2. 达到设置次数，或存在背包监控提前产生的待处理事件时，调用
   `AutomationHost.handleDungeonGear(...)`。
3. 副本清理复刻武当的营地分支：元宝回收 → 使用 `DungeonUtil.m15120v` 对应的营地坐标
   找“行脚商队” → 点击 NPC 第 4 个选项进入交易 → 贩卖杂物 → 快速贩卖装备 → 确认关闭。
   这条路径不回主城；普通背包事件仍复用 `AutoSellAutomation.runInline` 回城后去客栈。

   `DungeonUtil.v` 的完整坐标表（`mapType=199`）：

   | 等级 | 一般 | 精英 |
   |---|---|---|
   | 10/20/30/40/50 | `(107,26)` | — |
   | 60 | `(109,26)` | `(109,26)` |
   | 65 | `(110,26)` | `(107,26)` |
   | 70 | `(110,26)` | `(110,26)` |
   | 75 | `(106,24)` | `(115,21)` |
   | 80/90 | `(110,21)` | `(110,21)` |
   | 105/120/135 | `(106,24)` | `(106,24)` |
   | 150/165 | `(110,26)` | `(110,26)` |
4. 清理完成后恢复副本队列；普通/精英默认次数均为 3，可在“设置 → 副本”中分别改为 1–20。

武当原版的 `DungeonGearHandleAction` 还支持保留、存邮件、回收、分解、贩卖等细分规则；
当前助手已有的自动贩卖链是可直接验证的等价收尾，尚未把这些细分规则重新做成设置项。
