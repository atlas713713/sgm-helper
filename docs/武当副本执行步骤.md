# 武当 10–165 级副本执行步骤

本文是地球助手复刻武当副本逻辑的对照基准。内容来自武当 APK 的 `Dungeon10Action` 至
`Dungeon165Action`、70 级 `Dungeon70Action2`、`DungeonUtil`、`NPCDialog` 和
`Console` 反编译结果。坐标均为游戏地图坐标；NPC 点击坐标为 1280×720 屏幕坐标。

当前实现也按武当结构拆分：共享流程位于 `BaseDungeonAction`，
10、20、30、40、50、60、65、70、75、80、90、105、120、135、150、165 级分别由独立的
`DungeonXXAction` 类保存地图、NPC、对话行和副本路线。

## 一、所有副本共用的入场流程

1. 回城并等待主城地图加载完成。
2. 前往驻地引路员：
   - 洛阳、成都、建业：地图坐标 `(200,31)`。
   - 其他主城：地图坐标 `(210,33)`。
3. 到达后点击 NPC 快捷键 `(1208,410)`。
4. 只 OCR NPC 名字标题区域，确认标题为“驻地引路员”，点击第一行 `(251,450)`。
5. 等待进入“副本宫殿（一般）”。
6. 前往对应副本入口，宫殿坐标均为 `y=16`：

   | 等级 | 副本 | 宫殿入口 x |
   |---:|---|---:|
   | 10 | 桃园结义 | 26 |
   | 20 | 枭雄崛起 | 42 |
   | 30 | 三公战华雄 | 58 |
   | 40 | 十常侍之乱 | 73 |
   | 50 | 孙坚与玉玺 | 89 |
   | 60 | 界桥之战 | 105 |
   | 65 | 三英战吕布 | 121 |
   | 70 | 二狼劫献帝 | 136 |
   | 75 | 濮阳之战 | 152 |
   | 80 | — | 169 |
   | 90 | — | 184 |
   | 105 | — | 216 |
   | 120 | — | 232 |
   | 135 | — | 248 |
   | 150 | — | 263 |
   | 165 | — | 279 |

   80 级以上的副本名来自服务端配置，APK 里读不到，所以这几级不做副本名 OCR 校验。

7. 点击 NPC 快捷键，确认副本名后按“第四行、第三行”进入副本驻地
   （80 级以上跳过副本名校验，直接按这两行）。
8. 前往入口 NPC。通常坐标为 `(100,16)`；60 级是 `(102,16)`，70 级是 `(100,17)`。
9. 点击 NPC 快捷键，确认入口 NPC 标题，再执行该副本专属的固定行序列。
10. 等待副本地图加载，打开右侧自动寻路面板，开始按分段坐标执行。

## 二、NPC 对话的固定 OCR 和点击规则

武当的 `NPCDialog` 固定布局如下：

| 内容 | 武当区域/点击点 |
|---|---|
| NPC 名字 | 原始区域约 `(141,209)-(361,235)` |
| 第一行 | `(251,450)` |
| 第二行 | `(251,512)` |
| 第三行 | `(251,574)` |
| 第四行 | `(176,636)` |
| NPC 快捷键 | `(1208,410)` |

地球助手只 OCR 扩大后的标题区域 `(120,195)-(390,245)`。这个区域仍然只覆盖 NPC 名字，
不覆盖副本进度条、对话正文和按钮文字，因此不能把“副本进度”等文字误判成 NPC 对话框。
每次固定坐标点击前，都必须先确认当前 NPC 标题正确。

入口和出口的完整点击序列：

| 等级 | 入口 NPC | 入场行序列 | 武当配置的关键按钮 | 出口 NPC | 离场行序列 | 武当配置的奖励按钮 |

| 10 | 邹靖 | `3 → 3` | 进入 | 义勇军刘玄德 | `4 → 4` | 收下奖赏 |
| 20 | 曹嵩 | `4 → 4 → 3` | 详情告知、下一步 | 骑都尉曹操 | `4 → 4` | 领取奖赏 |
| 30 | 乱军太平道长 | `2 → 3 → 3` | 黄天、进入 | 乱军太平道长 | `4 → 4` | 第四行离场 |
| 40 | 长乐宫官吏 | `3 → 3` | 放弃闯入、离开 | 袁绍 | `4 → 4` | 领取奖励 |
| 50 | 历战老兵 | `4 → 3 → 3` | 下一步、入场、进入 | 孙坚 | `4 → 4` | 第四行离场 |
| 60 | 说书人 | `4 → 3 → 3` | 开始神游、进入 | 公孙瓒 | `4 → 4` | 答谢公孙瓒 |

剧情/“下一步”，再完成“离开/收下战利品”，不能只点一次或两次。

## 三、10 级：桃园结义

- 驻地：幽州边境。
- 入口 NPC：邹靖。
- 地图：599，方向从右向左。
- 入场对话：`第三行 → 第三行`。

执行顺序：

1. `part0` `x=599..504`：搜索 7 级或 10 级敌人；没有目标时每次向左移动随机 40–49 格，
   下限是 `min(599,504)-5=499`。`x<514` 时改为直接走门点 `(505,27)`。
   卡在 `x=514` 时的脱困点是 `(550,25)`。
2. `part1` `x=500..386`：同样搜索 7 级或 10 级敌人，随机推进下限 `381`；
   `x<397` 时走门点 `(387,27)`。卡在 `x=397` 时脱困点是 `(450,25)`。
3. `part2` `x=382..168`：**武当这一段完全不搜怪**，只做移动：
   `x>310` 走 `(290,27)`，否则走门点 `(170,27)`。
4. `part3` `x=159..39`：先用 `FindDungeonBossAction` 找副本 BOSS，再搜 10 级阵旗，
   随机推进下限 `13`；卡在 `x=39` 时脱困点是 `(110,25)`。
5. `part4` `x=38..18`：切换到离场步骤，前往 `(25,27)`。
6. 点击 NPC 快捷键，确认“义勇军刘玄德”，执行 `第四行 → 第四行`，领取“收下奖赏”并离开。

## 四、20 级：枭雄崛起

- 驻地：曹公府。
- 入口 NPC：曹嵩。
- 地图：599，方向从右向左。
- 入场对话：`第四行（详情告知）→ 第四行 → 第三行（下一步）`。

执行顺序：

1. `part0` `x=599..478`：搜索 18 级或 20 级敌人，随机推进下限 `473`；
   `x<491` 时走门点 `(480,27)`。卡在 `x=491` 时脱困点是 `(550,25)`。
2. `part1` `x=474..348`：不搜索敌人，直接走到 `(350,27)`。
3. `part2` `x=338..206`：先处理本段 BOSS，再处理 20 级阵旗，随机推进下限 `201`；
   `x<221` 时走门点 `(211,27)`。卡在 `x=221` 时脱困点是 `(280,25)`。
4. `part3` `x=199..91`：**只处理 20 级阵旗，不找 BOSS**，随机推进下限 `26`；
   卡在 `x=91` 时脱困点是 `(170,25)`。
5. `part4` `x=91..31`：先处理本段 BOSS，再处理 20 级阵旗，随机推进下限 `13`；
   卡在 `x=31` 时脱困点是 `(70,25)`。
6. `part5` `x=31..18`：不再搜怪，立即切换离场，前往 `(22,27)`。
7. 点击 NPC 快捷键，确认“骑都尉曹操”，执行 `第四行 → 第四行`，领取奖赏并离开。

## 五、30 级：三公战华雄

- 驻地：黄巾营寨（已由当前游戏画面和地球瘦子 OCR 日志确认）。
- 入口/出口 NPC：乱军太平道长；部分资源仍写作“黄巾太平道长”，OCR 两者都接受。
- 地图：599，方向从右向左。
- 入场对话：`第二行（黄天）→ 第三行 → 第三行（进入）`。

执行顺序：

30 级和其他副本不一样：**武当在这里几乎不用随机 40–49 格推进，整条路线都是固定路点**。

1. `part0` `x=599..451`：搜 30 级敌人，再找副本 BOSS。路点按当前 x 分段：
   - `x=580..599` → `(570,27)`
   - `x=510..579` → 第一次进入该区间先补一个 `(570,27)`（武当的 `flag570`），
     之后每次都走 `(500,27)`
   - `x=451..509` → 门点 `(458,4)`

   卡在 `x=473` 时脱困点是 `(570,27)`。
2. `part1` `x=448..301`：同样是 30 级敌人加副本 BOSS。
   - `x=420..448` → `(410,25)`
   - `x=350..419` → 第一次进入先补一个 `(410,25)`（`flag420`），之后走 `(340,25)`
   - `x=301..349` → 门点 `(304,27)`

   卡在 `x=317` 时脱困点是 `(430,25)`。
3. `part2` `x=297..151`：**只找副本 BOSS**（本项目按名字“董军阵旗”搜索），不搜普通敌人。
   - `x=245..297` → `(235,25)`
   - `x=205..244` → `(195,25)`
   - `x=151..204` → 门点 `(174,4)`
4. `part3` `x=148..33`：30 级敌人加副本 BOSS。
   - `x=95..149` → `(85,25)`
   - `x=55..94` → `(45,25)`
   - `x=33..54` → 直接走出口点 `(24,27)`
5. `part4` `x=32..20`：切换离场，前往 `(24,27)`。
6. 确认出口 NPC 标题，执行 `第四行 → 第四行` 离开。

## 六、40 级：十常侍之乱

- 驻地：长乐宫。
- 入口 NPC：长乐宫官吏。
- 地图：599，方向从右向左；副本起点约 `(570,25)`。
- 入场对话：`第三行 → 第三行`。

执行顺序：

1. `part0` `x=32..599`：只用 `FindDungeonBossAction` 找红名副本 BOSS，没有目标时
   **走固定阶梯路点**，不随机推进：

   | 当前 x | 目标 |
   |---|---|
   | `530..599` | `(520,25)` |
   | `430..529` | `(420,25)` |
   | `360..429` | `(350,25)` |
   | `285..359` | `(275,25)` |
   | `190..284` | `(180,25)` |
   | `120..189` | `(110,25)` |
   | `60..119` | `(50,25)` |
   | `< 60` | `(25,25)` |

   另外 `y<20` 或 `y>30` 时先把 y 拉回 25；连续卡住时走 `(x+100,25)` 两次。
2. `part1` `x=13..31`：走出口点 `(25,25)`。
3. 点击 NPC 快捷键，确认“袁绍”，执行 `第四行 → 第四行`，领取奖励并离开。

## 七、50 级：孙坚与玉玺

- 驻地：追忆之地。
- 入口 NPC：历战老兵。
- 地图：599，方向从左向右。
- 入场对话：`第四行（下一步）→ 第三行（入场/进入）→ 第三行`。

执行顺序：

1. `part0` `x<=49`：开场必须依次走三个点 `(46,6) → (46,45) → (60,45)`，
   不能从出生点直接点 `(60,45)`。
2. `part1..part6`（`50..110`、`112..194`、`205..287`、`312..388`、`399..484`、
   `495..581`）都跑同一个 `attackPart`：先 `FindDungeonBossAction` 找红名 BOSS，
   没有目标就调用 `toRight`。
3. **`toRight` 是固定 `+30` 一步、`y=27`**，上限 `max(25,570)=570`，越界后落在 `575`；
   不是随机 40–49，也不是走到各分段的门点。分段边界只用来算卡住时的脱困点
   （`next.x <= 分段终点` 时走 `分段终点-10`，否则走 `next.x+20`）。
4. `partCenter` `x=291..308`：与孙坚交互，确认 NPC 标题后点击第四行“交给我吧”。
5. `part7` `x=583..599`：切换离场，回到出口点 `(570,25)`。
6. 确认“孙坚”，执行 `第四行 → 第四行` 离开。

## 八、60 级：界桥之战

- 驻地：盘河桥西。
- 入口 NPC：说书人。
- 地图：599，多房间传送。
- 入场对话：`第四行（开始神游）→ 第三行（进入）→ 第三行`。

这里不能按 x 单调推进。**走廊坐标 `x<=98` 会重复出现，武当靠 `partStep` 记住
下一间房**，只看 x 会一直被送回第一间：

1. `partStep=0` 且 `x<=98`：清完走廊 BOSS 后依次走 `(71,10) → (71,4)` 进第一战斗房。
2. `x=105..198`（第一战斗房）：处理 BOSS；清空后依次走 `(114,40) → (114,46)` 传送出去。
3. 传送到 `x=505..528` 后点一次快捷键，`partStep` 变为 1。
4. `partStep=1` 且 `x<=98`：依次走 `(70,40) → (70,46)` 进第二战斗房。
5. `x=205..298`（第二战斗房）：处理 BOSS；清空后依次走 `(214,10) → (214,4)` 传送出去。
6. 传送到 `x=531..553` 后点一次快捷键，`partStep` 变为 2。
7. `partStep=2` 且 `x<=98`：依次走 `(90,27) → (94,27)` 进第三战斗房。
8. `x=305..398`（第三战斗房）：处理 BOSS；清空后依次走 `(380,27) → (394,27)`。
9. 传送到中央区域 `x=556..581` 后，先走到 `(570,27)`（等队友），再点击快捷键两次。
10. `x=405..479`：处理最终 BOSS；清空后走到 `(486,25)`。
11. `x=480..498`：前往出口 `(486,27)`。
12. 确认“公孙瓒”，执行 `第四行 → 第四行`，点击“答谢公孙瓒”并离开。

## 九、65 级：三英战吕布

- 驻地：虎牢关近郊。
- 入口 NPC：说书人。
- 地图：599，方向从左向右。
- 一般副本优先敌人等级：64；精英副本为 68。

执行顺序：

1. `x<=58`：走到 `(34,22)`，与刘备交互，确认标题后点击第三行“出击”。
2. `x=79..230`：搜索本段 BOSS，优先 64 级目标，推进到 `(245,27)`。
3. `x=231..250`：通过门点，进入 `x>=252` 的下一段。
4. `x=252..437`：搜索吕布/BOSS；清空后必须依次走

5. `x=440..537`：搜索 BOSS，推进到 `x=538`。
6. `x=538..580`：切换离场，前往 `(560,27)`。
7. 确认“刘备”，执行 `第四行 → 第四行`，收下战利品并离开。

## 十、70 级：二狼劫献帝

- 驻地：安邑郊外。
- 入口 NPC：毛玠。
- 地图：599，护送方向从左向右。
- 入场对话：`第四行（下一步）→ 第三行（出发/进入）→ 第三行`。

执行顺序：

1. `x<120`：保护“马车”，优先攻击“长安城驻军队长”和“长安白虎大门”，推进到 `(115,27)`。
2. `x=120..568`：继续护送；绝不把“马车”选为攻击目标。武当要求马车血量不低于 90%。
3. 当前段没有可攻击目标后，推进到出口 `(560,27)`。
4. 确认“曹操”，严格执行 `第四行 → 第四行 → 第四行`：
   先推进“下一步”，再完成“离开/收下战利品”。

70 级旧类有反编译缺损，本节以同一 APK 中可完整读取的 `Dungeon70Action2` 为准。

## 十一、75 级：濮阳之战

- 驻地：濮阳城外。

3. `x=79..129`：继续按名字优先级搜索，推进到阵旗点 `(130,27)`。
4. `x=130..179`：继续搜索剩余 BOSS，推进到出口 `(187,27)`。
5. `x>=180`：切换离场。
6. 确认“陈宫”，严格执行 `第四行 → 第四行 → 第四行`：
   先推进“下一步”，再完成“离开/收下战利品”。

## 十二、战斗 OCR 和恢复边界

1. 10、20、30、65、70、75 级使用上方引路列表；40、50、60 级使用下方列表。
2. 上方只读取固定中心线 `y=151/206/261/316/371`；下方只读取
   `y=294/349/404`。
3. 敌人 OCR 横向只接受 `x=950..1235`。副本进度条不在这些固定敌人行内，必须忽略。
4. 推进方式按副本区分，不是所有副本都随机走：
   - 10、20：随机 `40..49` 格，目标夹到 `min(分段起点, 分段终点) - 5`。
   - 30、40：完全不随机，走固定阶梯路点。
   - 50：固定 `+30` 一步、`y=27`，上限 570（越界落 575）。
   - 60：按房间传送，靠 `partStep` 决定下一间。
5. 每次攻击后重新识别当前位置和固定敌人行；没有敌人才执行本分段的门点/传送点。
6. 同一门点连续停留时，才执行对应副本的脱困坐标；不得跳过尚未完成的战斗分段。
7. 离场坐标用武当的 `exitLocation`，是每个副本的固定值，不能靠"把 x 当成 0 再问一次
   路线"推出来——从左往右打的 50/60/65/70/75 那样推会得到开场路点：

   | 等级 | 10 | 20 | 30 | 40 | 50 | 60 | 65 | 70 | 75 |
   |---|---|---|---|---|---|---|---|---|---|
   | exitLocation | `(25,27)` | `(22,27)` | `(24,27)` | `(25,25)` | `(570,25)` | `(486,27)` | `(560,27)` | `(560,27)` | `(187,27)` |

## 十三、80–165 级

### 和 10–75 的三点结构差异

1. **地图宽度不再固定是 599**：80/90/105/120/135/165 是 399，150 是 199。
   `BaseDungeonAction.dungeonMapMaxX()` 按副本返回。
2. **推进步长是固定 30 格，不是随机 40–49**：这些副本的 `toLeft`/`toRight` 传的
   `stepX` 都是 30，`y=27`，目标夹到 `min/max(分段起点, 分段终点) ∓ 5`。
3. **对话按按钮文字点行，不按固定行号**：副本名和入口/出口 NPC 名来自服务端
   `DungeonEntity`，APK 里没有。武当本来就是按 `npcButtonEnter` 之类的文字在
   NPCDialog 的四个选项框里找行，所以这些副本 OCR
   `(133,430)-(369,656)`，命中哪一行点哪一行。10–75 继续用已经验证过的固定行号。

入场按钮统一是 `随时可以出击` → `进入`（放弃是 `再稍做准备`），
奖励按钮 80/105/120/135/150/165 是 `收下奖赏`，90 是 `下一步 → 收下战利品`。

**保护目标血量按要求没有实现**：`protectMinHp`（0.8/0.9）需要读血条百分比，
目前只把 `protectName` 从攻击目标里排除，不会因为保护目标掉血而停下推进。

### 已知的简化

- 80 级只走武当默认的“下路”，没有实现 `(280,33)` 的上下路切换
  （`upEndY=20` / `downBeginY=26` / `downEndY=50`）。
- 165 级没有复刻大 BOSS 的状态机，是“中央没有可打目标就离场”。波次之间
  短暂空场时可能提前去出口；这时出口对话找不到“收下奖赏”会直接报错停下，
  不会误领。
- 90/105/135/150 的分段内推进用武当的通用 30 格 `toLeft`/`toRight`，
  没有逐段复刻各自的固定路点阶梯（120 和 40 是逐段复刻的）。
