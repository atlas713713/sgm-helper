# 三国M助手 MVP

一个仅供本机侧载的最小 Android 助手：

- 打开 BlueStacks Air 中的《三国群英传M 亚服》（`hk.phx.khm.cs`）。
- 通过 Android 无障碍服务显示可拖动的“辅”悬浮按钮和小型控制菜单。
- 每天按各自设定时间执行“膜拜”和“军团奖励”流程。

## 构建

```sh
export JAVA_HOME=/opt/homebrew/opt/openjdk@17/libexec/openjdk.jdk/Contents/Home
export ANDROID_SDK_ROOT=/opt/homebrew/share/android-commandlinetools
export PATH="$JAVA_HOME/bin:$PATH"
./gradlew clean lintDebug assembleDebug
```

APK 输出到 `app/build/outputs/apk/debug/app-debug.apk`。

## 安装与首次设置

1. 在 BlueStacks Air 的默认“地球瘦子”实例中选择 **Install APK**，安装上面的 APK。
2. 打开“三国M助手”。如果无障碍开关不可用，先进入应用详情，点击右上角 `⋮`，选择“允许受限设置”。
3. 返回助手，打开无障碍设置，启用“三国M助手悬浮服务”。
4. 返回后助手会打开游戏；游戏右上角会出现可拖动的“辅”按钮。
5. 点击“辅”展开“练级 / BOSS / 副本 / 终止 / 设置 / 退出”小菜单；“设置”会打开非全屏的“练级 / 定时”菜单。

- 在“设置 → 登录账号”保存账号和密码；凭据仅保存在当前模拟器的应用私有数据中。
- 助手打开游戏或定时任务唤起游戏时，会先等待加载并自动处理最新公告、开始游戏、快捷/账号登录和福利页；已记住登录时直接继续。

- “练级”先检查并执行到期军务，然后恢复自动练级；只有练级主线会运行军务。
- “BOSS”进入野王 / 世界王选择；BOSS 主线运行期间不执行军务。
- “副本”可勾选副本等级，按等级从低到高依次扫荡；选择会自动保存，副本运行期间不执行军务。
- “练级 → 设置”可选择荒野 1–15 区、目标怪物和 1–8 分流；启动后经荒野传送官按每页 3 区的固定位置进入目标区，再切换分流、选择怪物并开启自动攻击。
- 膜拜默认每天 `10:30` 自动执行；进入“设置 → 定时 → 膜拜”，通过系统时钟选择时间，确认后立即保存并更新下一次执行时间。
- 军团奖励默认每天 `10:10` 自动执行；“设置 → 定时 → 军团奖励”可单独修改时间。
- 勾选“自动军务”后，开始练级会先检测一次军务，并按识别到的任务冷却时间设置最近闹钟；没有冷却时间时从本次检测起 `3h` 兜底，不使用默认 `10:30`。未勾选则直接练级且不排程军务。
- “定时”页面同时列出“膜拜 / 自动军务 / 领取福利×2 / 军团奖励”；领取福利默认勾选，每天在 `12:05` 和 `18:05` 执行。时钟修改第一次时间，第二次自动安排在 `6h` 后；“立即执行”仍可随时使用。
- 每个已实现任务都有复选框；取消勾选会取消该任务的定时触发，但“立即执行”仍可使用。
- 每个任务右侧显示“立即执行”；膜拜、自动军务、领取福利和军团奖励均可直接打开游戏并执行。
- “终止”会取消当前动作链并把默认主线重置为练级。
- 任务运行时，屏幕顶部正中显示不拦截触摸的小字进度；完成、暂停或终止后自动隐藏。

定时触发时，助手会打开《三国群英传M》，等待 `10s` 加载游戏，再开始任务。无障碍服务必须保持启用。

## 膜拜流程

每个动作完成后等待 `1s`：

1. 点击右上角菜单 `(1215, 58)`。
2. 检查排行榜固定区域；检测不到时在右侧菜单从 `(1120, 250)` 向下滑到 `(1120, 350)`。
3. 点击排行榜：未滚动时 `(1190, 230)`，滚动后 `(1190, 330)`。
4. 点击荣耀厅 `(852, 358)`。
5. 点击大丰收城 `(165, 196)`，再点击膜拜 `(636, 623)`。
6. 点击国战榜 `(167, 351)`，再次点击膜拜 `(636, 623)`。
7. 点击右上角关闭按钮 `(1233, 55)`。

## 军团奖励流程

每个动作完成后等待 `1s`：

1. 点击右上角菜单 `(1215, 58)`，再点击军团 `(994, 245)`。
2. 点击主页 `(409, 101)`、俸禄盒子 `(978, 178)`、确认 `(531, 406)`。
3. 点击贡献 `(950, 612)`。
4. 点击一般贡献 `(380, 569)` 六次。
5. 点击右上角关闭 `(1106, 49)` 两次。
6. 等待 `10s` 后使用第一个标记卷并恢复自动练级。

## 自动军务流程（当前阶段）

所有点击完成后统一等待 `2s` 再执行下一动作；OCR 重试间隔保持 `1s`。
自动攻击的开启和关闭都会等待按钮出现，最多重试 `20` 次。
在检测或点击自动攻击前，共享的 `ScreenGuard` 会先连续两次点击 `(640,20)` 关闭普通遮挡窗口；福利窗口不会响应该坐标，因此仍单独识别并点击右上角关闭。
“快速抵达”只截取任务窗口底部区域并放大 `2x` 识别；OCR 拆成“快速 / 抵达”等相邻片段时会合并定位，不使用固定点击坐标兜底。

0. 每次初始化先在当前位置打开“任务 → 进行中”，只查找“巡狩军团荒野”和“补充军团物资”，优先检查荒野的收集数量；找到进行中的收集任务时不回城，也不进入承接流程。两个收集任务都没有时才关闭任务窗口、回城，再打开“军团 → 可承接”检查并承接任务；单独存在“勇讨军团天将”不算收集任务。所有回城入口都会先确认自动攻击已关闭，再连续点击两次回城。
1. 关闭自动攻击；OCR 支持独立或合并的“敌人 / 寻路”标题。检测到自动寻路栏时点击关闭并重新确认，仍存在就最多重试 `5` 次，确认消失后才继续查找任务。
2. 打开右侧任务栏，进入“军团 → 可承接”。
3. 按顺序逐项选中“补充军团物资 / 巡狩军团荒野 / 勇讨军团天将”，再合并右侧详情区的 OCR 片段检查冷却，避免“冷却 / 时间”被拆行后漏判。兼容“冷却时间 / 冷卻時間 / 冷却 + 时长”及“小时 / 分钟 / 分秒”格式，按任务分别记录“当前时间 + 冷却时长 + 1 分钟”并检查下一项；没有冷却信息才视为可承接。随后通过 OCR 点击“快速抵达”，再开启自动寻路：补充物资等待“常务军士”，巡狩荒野等待“荒野军士”。对话出现后先 OCR 点击“想”，再 OCR 点击“离开”完成承接；如果对话没有“想”，则直接点击“离开”。
4. 三项都检查后，若“补充军团物资”和“巡狩军团荒野”都在冷却，直接结束军团任务并开始练级；“勇讨军团天将”只承接，目前不执行。否则切到“进行中”，并且只在任务窗口左侧列表查找任务；任务确实出现在“进行中”后才能判断物品数量。若未出现则返回“可承接”重试一次，不能用右侧任务栏的同名文字和库存数量直接判定完成。
5. 完成承接后先执行“巡狩军团荒野”，再执行“补充军团物资”。荒野每 `5min`、物资每 `3min` 打开“任务 → 进行中”检查；顶部进度会显示下一次检查的具体时间。选中当前任务后，合并右侧“任务目标”区域的 OCR 片段并识别 `数字/数字`；例如 `(250/250)` 表示已足够。OCR 明确识别物资未满时，关闭任务窗口并再次 OCR 点击右侧“补充军团物资”，确保角色继续收集，然后保留下一次 `3min` 复查；这次点击即使 OCR 失败也不会结束军务。只有 OCR 完全读不到进度时，才用左侧大型绿色完成勾兜底。
检查荒野收集前会先 OCR 当前地图名；只有识别到“荒野修炼X区”才视为正在荒野。荒野任务未满且当前不在荒野时，自动重新执行“军团 → 荒野修炼 → 前往荒野”；已在荒野时不重复传送。
   打开任务窗口后会通过“任务 / 进行中 / 可承接 / 任务计数 / 任务目标 / 快速抵达 / 放弃任务”等多个特征再次 OCR 确认；首次打开失败后会先检查并关闭自动寻路栏，再重新打开。任务未找到时最多执行 `3` 轮“确认/重开窗口 → 进入进行中 → 重新查找”，不会因顶部进度文字遮住标题或一次 OCR 漏识别立即退出。
6. 先检查“巡狩军团荒野”并读取荒野区号。先 OCR 检测任务窗口：窗口已打开时直接点击“进行中”，不能再次点击右侧任务按钮把窗口关闭；窗口未打开时才打开任务窗口。材料已满时点击“快速抵达”，再检测是否出现“自动寻路”：出现就点击，未出现则直接等待交付对话；最后点击“离开”并进入物资阶段。未满才进入荒野。
7. 打开菜单后先在菜单区域连续向下拖动 `3` 次，将内容归位到最顶部；随后精确 OCR 查找“军团”最多 `5` 次，仍找不到就用顶部布局固定坐标 `(995,270)` 点击“军团”。进入军团后点击“荒野修炼 → 前往荒野”，并确认画面出现“荒野营地”。
8. 点击自动攻击旁边的自动寻路图标，选择“寻路 → 荒野传送官 → 目标荒野修炼区”。不再固定等待 `5s`；OCR 在底部地图标题区确认任意“荒野修炼X区”加载完成后，关闭自动寻路栏并点击右侧“巡狩军团荒野”。随后立即检测短暂出现的“执行任务：”；未确认时重点一次，只有确认成功才关闭寻路栏并启动 `5min` 收集计时。
9. 巡狩材料收集满后先关闭任务窗口并回城，等待 `5s`，再重新打开“任务 → 进行中 → 巡狩军团荒野”，通过 OCR 点击“快速抵达”。随后短暂 OCR 检测“自动寻路”：出现就点击，未出现不报错并直接等待对话。每个任务点击“离开”完成交付后，都会重新打开“可承接”并 OCR 读取该任务的新冷却时间；只有最终识别失败才使用 `3h` 兜底。物资每 `3min` 检查，完成后才结束本轮军务。
10. 自动军务全部完成后以 `1s` 间隔点击两次回城，等待 `10s` 后点击物品栏第一个标记卷 `(50, 625)`；至少等待 `5s` 加载，检测到自动攻击按钮后确保它已开启。计时器到期后停止练级、执行军务，完成后再继续练级。

## 代码结构

- `HelperAccessibilityService`：悬浮界面、生命周期、点击、截图和 OCR 等 Android 能力。
- `AutomationHost`：自动流程可使用的最小平台接口，避免各功能直接依赖整个 Service。
- `ScreenGuard`：共享的画面清理规则；自动攻击开关会统一调用。所有关闭福利的入口统一使用 `closeWelfareWindow`，关闭后必定 OCR 检查“尚未领取的奖励”，有弹窗就点击“关闭界面”。
- `TrainingAutomation`：练级流程。
- `TaskAutomation`：军务的承接、执行、冷却和完成检测。
- `RewardAutomation`：膜拜与军团奖励流程。
- `WelfareAutomation`：福利类目红点检测、领取按钮处理和类目滚动；每个福利类目有独立的 `WelfareCategory` 子类，特殊领取规则可只覆盖对应类。
- `DungeonSweepAutomation`：副本扫荡流程；固定坐标打开副本和扫荡，OCR 仅用于在左侧列表定位所选等级。
- 在线奖励会向左、向右各检查一遍，并补点所有可见奖励槽避免 OCR 漏领；每日挑战 OCR 读取“每日完成奖励”下方的 `x/7`，按完成 `1 / 3 / 5 / 7` 次点击对应固定奖励坐标，奖励点击高度为 `y=550`。关闭福利后若出现“尚未领取的奖励”，自动点击“关闭界面”。
- 每日应援使用独立规则，精确 OCR 查找并点击“立即领取”；未找到时视为当前时段不可领取并继续流程。
- `BossAutomation`：野王自动化；设置模式 1、使用标记卷、按 `y=25` 横向往返并在移动过程中持续搜索红名 BOSS，击败后继续当前路段，并在每轮结束后循环切换 1–8 分流。
- `ChannelSwitcher`：共享的 1–8 分流切换流程。
- `WildernessNavigator`：共享的荒野营地、传送官、分页选区和地图加载流程；练级与军务共同调用。
- `AntiCheatVerification`：切换分流后检测反外挂窗口，以人脸检测判断三个头像的正向角度，旋转后提交验证；窗口消失后才继续寻敌。

新增功能时优先放进对应的功能类；只有 Android 平台操作才放进 `HelperAccessibilityService` 并通过 `AutomationHost` 暴露。

助手始终记录当前主线（练级 / 打 BOSS / 副本）。任何自动流程失败时，错误信息会写入诊断日志，
并恢复当前主线；军务、福利和奖励等次要任务不会覆盖主线。前三次错误在 `5s` 后恢复，
连续失败时改为 `60s` 后恢复同一主线。
屏幕截图如因 Android 最小间隔限制返回错误码 `3`，助手会每隔 `1s` 自动重试，最多 `5` 次。

应用会把服务生命周期、每步流程进度、重试、失败和未捕获崩溃持久写入
BlueStacks 共享目录 `SGMHelperLogs`。三个模拟器按名称和各自的 `ANDROID_ID`
生成独立文件：`sgmhelper-地球瘦子-<ANDROID_ID>.log`、
`sgmhelper-栗威-<ANDROID_ID>.log` 和 `sgmhelper-地球-<ANDROID_ID>.log`，不会互相覆盖。

## 固定游戏环境与坐标

- 游戏画面固定为横屏 `1280 × 720 px`，DPI 固定为 `240`（Android density `1.5`）。
- 游戏坐标原点为画面左上角 `(0, 0)`，`x` 向右、`y` 向下；自动点击使用像素坐标，不使用 dp。
- 常规小地图的游戏范围为 `x=0..600, y=0..50`，可点屏幕区域为 `x=436..844, y=610..690`。`tapMapCoordinate`会换算后点击；边界坐标内缩 `1` 格以避免点到边框，例如游戏 `(300,50)` 点击屏幕 `(640,689)`。
- 悬浮按钮默认贴在最左下角，任务执行期间保持当前位置不变。
- 右上角“菜单”按钮区域约为 `x=1170..1260, y=10..105`，安全点击中心为 `(1215, 58)`。
- 坐标依据：用户提供的 `1010 × 568` 等比例游戏截图换算到 `1280 × 720`。
- 自动攻击检测区域为 `x=1200..1260, y=440..510`：红色表示已开启，蓝色表示未开启；未开启时点击 `(1210, 480)`。

命令行安装前，先在 BlueStacks 设置中启用本机 ADB。默认“地球瘦子”实例会同时显示
`emulator-5554` 和 `127.0.0.1:5555`；安装时必须使用前者，后者在 BlueStacks Air
5.21 中会在传输 APK 时断开：

```sh
"/Applications/BlueStacks.app/Contents/MacOS/hd-adb" \
  -s emulator-5554 install -r -t \
  "$PWD/app/build/outputs/apk/debug/app-debug.apk"
```

本 MVP 不包含反检测或远程调度功能。
